# DotaPulse Coach 3.0

Мобильная веб-панель для Dota 2, аккаунт 294194492.

## Что уже работает
- Статическая адаптивная панель в [index.html](index.html)
- Общий винрейт, последние 5/10/20 матчей, герои, K/D/A, ассисты, лечение, GPM/XPM
- Переход к конкретному матчу OpenDota
- Автоматическая загрузка [data/latest.json](data/latest.json) с GitHub; если файл недоступен, резервный снимок 2026-11-02
- Явная дата сбора и маркировка расчётного MMR

## Публикация сайта
В GitHub откройте **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save**.
После публикации предполагаемый адрес: https://aruhaa222.github.io/dota2-daily-tracker/
Публикация GitHub Pages не подтверждена автоматически. Проверьте статус в Settings → Pages.

## Обновление
Ежедневная задача ChatGPT DotaPulse Coach 3.0 запланирована на 16:00 Europe/Moscow (гибкое время запуска).
Её инструкция обновляет data/latest.json только после успешного сбора OpenDota и записи в GitHub. Это инструкция автоматизации, не отдельный гарантированный серверный сборщик.

## Ограничения
- OpenDota может задерживать данные или не предоставлять позиции, варды, стаки и другие метрики.
- computed_mmr не равен подтверждённому MMR Valve.
- По K/D/A нельзя установить причину смерти или правильность применения способностей.
- Не храните приватные токены в публичном репозитории.
