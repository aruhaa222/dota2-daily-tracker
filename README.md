# DotaPulse Coach 5.0

Гибридная система аналитики Dota 2: адаптивный веб-сайт и локальный Windows-компонент для каталога реплеев.

**Сайт:** https://aruhaa222.github.io/dota2-daily-tracker/

## Веб-панель
- Винрейт, KDA, герои, последние матчи, динамика по дням и тренерские упражнения.
- Данные OpenDota собираются GitHub Actions через `scripts/collect.py`.
- История матчей в `data/match-history.json` пополняется без повторов (до 1000 записей).
- Раздел **Replay Bridge** импортирует локально JSON-каталог, экспортированный Windows-программой. Файл не отправляется на сервер.

## Windows Replay Bridge (первая версия)
Файл: [desktop/replay_bridge.py](desktop/replay_bridge.py)

Требования: Windows 10/11 и Python 3.10+ с Tkinter (обычно входит в стандартный установщик Python).

1. Скачайте репозиторий (**Code → Download ZIP**) и распакуйте.
2. Установите Python с https://www.python.org/downloads/windows/ при необходимости.
3. Запустите `desktop/replay_bridge.py` двойным щелчком или командой `py desktop/replay_bridge.py` из папки репозитория.
4. Нажмите **Выбрать**, укажите папку с файлами `.dem` (обычно `steamapps/common/dota 2 beta/game/dota/replays`), затем **Сканировать**.
5. Нажмите **Экспорт JSON**, сохраните `dotapulse-replays.json`.
6. На сайте в разделе **Replay Bridge** выберите **Загрузить каталог JSON**.

Программа сканирует файлы локально, определяет ID матча из имени файла, показывает размеры и даты, открывает соответствующую страницу OpenDota. Она **не разбирает внутреннее содержимое .dem**, не анализирует перемещения/способности и не загружает реплеи в сеть. Веб-импорт тоже локальный.

## Безопасность и ограничения
- Не храните Steam-пароли, токены и приватные реплеи в публичном GitHub.
- Веб-панель использует общедоступные данные OpenDota, которые могут запаздывать.
- Расчётный MMR не является официальным MMR Valve.
- Для глубокого разбора реплеев понадобится совместимый с текущей версией Dota 2 DEM-парсер и отдельный этап реализации.

## Windows 11: готовый EXE без установки Python
1. Откройте [Build Windows Replay Bridge](https://github.com/aruhaa222/dota2-daily-tracker/actions/workflows/build-windows.yml).
2. Нажмите **Run workflow → Run workflow** (либо дождитесь автоматического запуска после изменения Windows-кода).
3. Откройте успешный запуск (зелёная галочка), внизу в разделе **Artifacts** скачайте **DotaPulse-Replay-Bridge-Windows11**.
4. Распакуйте ZIP, запустите `DotaPulse-Replay-Bridge.exe` на Windows 11.
5. При предупреждении Windows SmartScreen проверьте источник и файл; неподписанные EXE могут вызывать предупреждения. Не отключайте защиту системы ради запуска.

EXE собирается GitHub Actions на `windows-latest` через PyInstaller. Готовый бинарник не хранится в репозитории и доступен как artifact 30 дней. Пока сборка не завершилась успешно, наличие EXE не подтверждено.
